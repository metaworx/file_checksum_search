# AP CIGreen v1.0: what the first full CI run found

> **Status: proposal, 2026-09-25.** The v0.20.0 tag ran the pipelines on
> both hosts for the first time since 2026-08-23. Every job that failed is
> a pipeline, harness or environment defect; none is in the app. The
> release stays where it is; these land after it and run on the next push.

## Analysis

1. **GitHub `lint`: stale apt index.** The manifest step installs
   `libxml2-utils` without `apt-get update`; the runner's index named a
   build that no longer existed (404).
2. **GitHub PHPUnit, all six matrix jobs: the HTTP server runs as root.**
   `test.yml` starts `php -S 127.0.0.1:80` under `sudo` because four test
   classes hard-code `http://127.0.0.1`. Every home the server creates on
   a test account's first login is root-owned, so the PHPUnit process,
   the runner user, cannot create or delete inside it: three
   `RulesApiTest` cases fail on `newFolder()` in alice's home, and
   `ReachTest` logs `unlink(...welcome.txt): Permission denied`. Under
   ddev both sides are one user. The tests are from 2026-09-01 and had
   never run on CI.
3. **Cypress on Nextcloud 33, both hosts: `ResizeObserver loop completed
   with undelivered notifications`.** A benign Chrome notification. The
   support file's `uncaught:exception` handler fails a test when the
   message or stack contains the app id, and here the stack's only frame
   is the page URL, `…/apps/file_checksum_search/…`. 37 failures on
   GitHub, 32 on GitLab, one cause.
4. **Cypress on Nextcloud 33, GitLab: `occ user:auth-tokens:add` is
   broken in 33.0.9.** GitLab installs `latest-33.zip`; that release's
   command reads `$input->getOption('login-name')` without defining the
   option and fails for everyone (`The "login-name" option does not
   exist`). GitHub clones the `stable33` branch, where it is fixed. The
   `sudo-tokens` spec mints its app password with that command in
   `before()`, so the whole spec is skipped-and-failed there.
5. **Cypress on Nextcloud 34, both hosts: a minted account's first
   WebDAV requests fail.** GitLab: `PUT` of `a.txt` into a fresh
   account's root answered 412, and `PUT` into a folder whose `MKCOL` was
   sent with `failOnStatusCode: false` answered 404. GitHub's release run:
   the same `nobody` case landed on the login page. All are the first
   requests after `fciasMakeAccount()`, when the server is still setting
   the home up; locally the instance is faster than the spec.
6. **Not diagnosed:** GitHub's release run also had `status.cy.js`
   "counts what a reset disowned" see `Total: 0` for 3; it passed in the
   next run. Left alone until it recurs.

## Implementation Plan

1. **[FIX] The GitHub pipeline's two environment defects.**
   `.github/workflows/test.yml`: `sudo apt-get update -qq` before the
   install in `lint`; the HTTP server started unprivileged after
   `sudo setcap cap_net_bind_service=+ep` on the resolved PHP binary, so
   port 80 stays and the server runs as the runner user.
   **Verification:** the next push's `lint` and PHPUnit jobs green.

2. **[FIX] The e2e support file: the notification ignored, the account
   warmed.** `tests/e2e/support/e2e.js`: the `uncaught:exception`
   handler returns false for the ResizeObserver message before the
   ownership check; `fciasMakeAccount()` ends with a `PROPFIND` on the
   account's WebDAV root as the account, retried until it answers 207,
   so the home exists before a spec writes into it. `duplicates.cy.js`:
   the `MKCOL` fails loudly instead of `failOnStatusCode: false`.
   CHANGELOG: exempt, tests only.
   **Verification:** the paired local run `duplicates.cy.js,checksums.cy.js`
   green; the next push's Cypress jobs on 33 down to the sudo-tokens
   failure, on 34 green.

3. **[FIX] The sudo-tokens spec mints its app password over OCS.**
   `tests/e2e/sudo-tokens.cy.js`: `GET /ocs/v2.php/core/getapppassword`
   as the holder, with Basic auth, replaces the `occ user:auth-tokens:add`
   call; the listing that follows stays on occ. Works on every server
   version the matrix has; independent of the 33.0.9 defect.
   CHANGELOG: exempt, tests only.
   **Verification:** `sudo-tokens.cy.js` green locally on 34 and on
   GitLab's 33.
