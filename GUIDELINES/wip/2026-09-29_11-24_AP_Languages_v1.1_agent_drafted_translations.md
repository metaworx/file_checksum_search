## Analysis

- **Team folders' label and name.**
  - `src/rules-vue/bands.ts:131` builds the scope label as
    `` `${groupFolderTerm}: ${name}` ``, a concatenation §3.7 forbids.
  - `GroupFolderService::appName()` reads `getAppInfo()` without a
    language, so `{folders}` is always "Team Folders". The groupfolders app
    translates its own name (`de`: "Team-Ordner", `fr`: "Dossiers
    d'équipe"); core's `NavigationManager` translates an app's name
    through that app's catalogue, `IFactory::get($app)->t($name)`.
- **Texts that lack context** (the tool reads a `TRANSLATORS` comment only
  from the line directly above the call):
  - `Search {folders}…` (`RuleForm.vue:212`): the placeholder of the search
    box that picks the one team folder a rule addresses. The comment above
    it belongs to the line before. Three drafts read it as searching inside
    the folders.
  - `Search anywhere`, `Min`, `Limit` (`DuplicateListing.vue`): the
    duplicates filter. The switch lets the typed text match anywhere in a
    checksum instead of only its start; Min is the smallest group to list,
    Limit the groups per page. Beside each other, Min and Limit read as one
    quantity's bounds.
  - `"<band>.<position>"` (`RuleTable.vue:84`): the comment says "keep as
    it is"; the column shows two numbers, and the German and all eight
    drafts translate the two words.
- **German corrections** (from the reviews):
  - Include / Ignore / Exclude is a rule's type; the idle banner says
    'Modus "include"', the glossary "a mode's name". The labels stay
    translated.
  - The Reset hint's "verwaist" echoes the orphan purge ("Bereinigung
    verwaister Einträge"), which removes entries of deleted files; a reset
    marks stored hashes `stale:reset` and the queue drain
    (`ProcessPendingUpdates` → `RuleService::clearDisownedFiles`) clears
    them.
  - "Recalc" is "Berechnen" under the heading "Neu berechnen".
  - "{folders} durchsuchen …" searches inside the folders.

## Implementation Plan

1. **[FIX] The team folders' label and name can be translated.**
   - `bands.ts`: `t('file_checksum_search', '{folders}: {folder}', …)` with
     a `TRANSLATORS` comment; the `app:groupfolders` fallback stays a name.
   - `GroupFolderService::appName()`: the name through the groupfolders
     app's own catalogue (`IFactory`); its test extended.
   - `l10n.sh update`; `de`/`de_DE` translate the new text; CHANGELOG
     Fixed.
   **Verification:** Vitest, the unit tests, `l10n.sh check`, ESLint, ECS.
2. **[UPDATE] Translators get the context the texts lacked; the German
   follows it.**
   - `TRANSLATORS` comments on `Search {folders}…`, `Search anywhere`,
     `Min`, `Limit`, and a specific one on `"<band>.<position>"`.
   - German: type not mode (banner and glossary), the Reset hint, "Neu
     berechnen" for Recalc, "{folders} suchen …", and the optional Search
     anywhere / Min / Limit wording the user picks.
   **Verification:** `l10n.sh check`, the German specs.
3. **Apply the reviews** (agents, in their worktrees): fast-forward to
   master, `update`, translate the new text, apply the review's findings
   and the new comments' context, end each manifest description with the
   machine-translation note, rerun `check` and the placeholder check, copy
   to the scratchpad.
   **Verification:** per language, `check` complete and 0 placeholder
   problems.
4. **Integrate**, one commit per language: `.po`, glossary, `l10n/`,
   `info.xml` (`fr`, `es`, `it`, `nl`, `ja`, `pl`, `pt-br`, `zh-hans`),
   CHANGELOG Added.
   **Verification:** `check`, the manifest schema, Vitest.
5. Remove the worktrees and their branches.
