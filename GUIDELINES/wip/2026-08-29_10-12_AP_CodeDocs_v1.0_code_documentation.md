## Analysis

### Block 0 — code findings that block doc fixes (decide first)

1. **`lib/Service/HashCalculationService.php:763-793` (`recalcAllExistingAlgos`)** — when hashes
   exist, line 785 assigns `MetadataService::getHashes()`'s **algo⇒hash map**
   (lib/Service/MetadataService.php:86-109 fills `$hashes[$algo] = …`), then line 788 passes
   `array_values($algos)` — the **hash strings** — to `recalcHashes()` as algorithm names, and the
   `foreach ($algos as $algo)` at 792 iterates hash values, so `processed` can never count real
   results. `array_keys()` is almost certainly what was meant. The docblock's
   `@return … algos: string[]` currently masks this. → fix the code (own `[FIX]` commit + changelog
   bullet), then the docblock is already true.
2. **`lib/Service/MetadataService.php:1019-1027` (`parseQueryTerm`)** — regex character class
   `[a-zA-F0-9]` (mixed ranges; `a-z` plus `A-F`) looks like a typo for hex matching; decide
   intended range, fix code or document why. (Also the method name `getAlgorithmenFromKey` at 995
   is misspelled — rename only if callers are few; else note.)
